# 衝突編號：CONFLICT-005

## 狀態：`resolved`

## 衝突描述
- **角色 A（書籍需求者 / 買家）** 需要：享有完整 **7 天鑑賞期**，可在期內檢查書況、發現落差時發起爭議並從 escrow 取回款項；這是消保法賦予的權利，也是買家敢於下單的信任基礎。
- **角色 B（書籍提供者 / 賣家）** 需要：**盡快收到款項**以確認交易完成、回收成本；對「寄出後對方惡意退貨、誣告書況不符」有明確恐懼，款項長期卡在 escrow 是其核心痛點之一。spec 驗收條件明示「買家確認取貨 + 7 天鑑賞期結束 → 款項自動撥入賣家帳戶」，意味著賣家從寄出到實際收款最長可達 10–14 天以上。
- **為什麼衝突**：買家的鑑賞期權利與賣家的撥款速度本質上是「資金留置時間」的對立：買家希望時間越長越安全，賣家希望時間越短越好。v1.1 雖以 escrow 機制處理基本框架，但 pre-flag 已指出「最終款項延遲仍為潛在糾紛點」。此衝突牽動賣家留存（賣家若覺得收款太慢會減少刊登）、買家信任（若鑑賞期被縮短或設定棘輪會失去消保保障）、糾紛率（≤ 3% 目標）以及平台 escrow 的資金壓力。

## AI 分析
此衝突是 **消費者保護 vs 賣家現金流** 的經典張力，在所有引入鑑賞期的 C2C 平台都會出現。台灣特殊脈絡：

1. **消保法 7 天鑑賞期**：屬法定權利，平台無法用條款排除，但可在「賣家為個人非企業」時主張不適用——這在 C2C 二手書場景灰色地帶極大。
2. **Escrow 資金壓力**：平台需有足夠的營運資金或銀行履約保證來應對「同時 N 筆訂單卡在 escrow」的狀態，MVP 階段需評估資金成本。
3. **賣家現金流敏感度**：若賣家是清書處理閒置物，現金流不敏感；若賣家是個人副業／週轉者則高度敏感。spec 的目標族群擴展至所有讀者後，後者比例可能上升。
4. **惡意退貨風險**：書況爭議若無客觀標準（如照片比對、出貨前驗收），賣家極易感到「被誣告」，這正是其核心恐懼。
5. **潛在折衷工具**：(a) 信用良好賣家加速撥款；(b) 鑑賞期分級（取貨後 N 天無爭議自動結案）；(c) 部分款項先撥（如 50% 取貨後撥、50% 鑑賞期後撥）；(d) 賣家可選擇加入「快速撥款 + 保證金」方案。
6. **與 CONFLICT-004 的耦合**：書況爭議的處理流程牽動管理員存取個資的層級，需協同設計。

## 解決方案
- [ ] 方案 1（優先滿足角色 A，買家）：嚴格執行「取貨 + 7 天無爭議才撥款」，鑑賞期內買家可無條件發起爭議由管理員裁決；撥款最慢 14 天到帳。買家信任最大化，但賣家現金流壓力大，可能流失對現金流敏感的賣家。
- [ ] 方案 2（優先滿足角色 B，賣家）：縮短為「取貨後 48 小時無檢舉即自動撥款」，超過 48 小時的爭議改由買家自行向賣家求償（平台不再 escrow 兜底）；賣家現金流順暢，但買家失去消保法等級的保障，平台信任受損。
- [x] **方案 3（折衷分階段，採用）**：(a) MVP 維持「取貨 + 7 天 = 撥款」作為預設安全網；(b) 推出「賣家信用分數」機制——累積 N 筆成功交易與 0 糾紛的賣家可申請「快速撥款方案（取貨後 48 小時撥款 80%、鑑賞期結束撥款剩餘 20%）」；(c) 鑑賞期內買家若已點選「確認無誤、提早結案」按鈕，立即觸發全額撥款；(d) 對於高爭議賣家則維持完整 7 天鎖款；(e) 在賣家刊登介面預先揭露「預估到帳日」以管理期待。

## 決策紀錄
- **決策者**：使用者本人（Spec 擁有者）
- **決策日期**：2026-04-08
- **選擇方案**：方案 3（折衷分階段）
- **理由**：守住消保法底線——7 天鑑賞期是台灣消保法賦予消費者的法定權利，不可在標準設計中犧牲。方案 2 的 48 小時 + 自行求償實質上讓平台 escrow 兜底失效，違反消保法精神且會摧毀買家信任。方案 3 在守住「7 天預設安全網」的法定底線前提下，額外提供「提早結案」輕量機制作為賣家現金流品質的改善——這是本棟費最少的方案。
- **後續行動**：
  - 角色 B 驗收條件明確化為「預設鑑賞期 7 天自動撥款；買家點選『提早結案』則立即撥款」
  - 角色 B 刊登介面新增「預估到帳日」揭露以管理期待
  - 角色 C 驗收條件新增「可點選『確認無誤、提早結案』按鈕」；**UI 設計需反脅迫**（避免賣家施壓買家，至少要在取貨後 24 小時才顯示此按鈕）
  - 信用分數機制預留欄位但 MVP 不啟用（避免冷啟動無資料無意義）
  - 爭議處理流程與 CONFLICT-004 協同：7 天內爭議由「資深客服」層級裁決
  - MVP 階段平台資金需預估 escrow 壓力（同時 N 筆訂單卡在 7 天窗口的資金成本）

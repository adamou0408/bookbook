# 衝突編號：CONFLICT-001

## 狀態：`resolved`

## 衝突描述
- **角色 A（書籍提供者 / 賣家）** 需要：刊登流程極簡化，單本書 ≤ 2 分鐘完成，拍照、自動補全、最少欄位輸入，否則會在流程中途放棄（流程太繁瑣是其核心恐懼之一）。
- **角色 B（平台管理員）** 需要：每筆刊登都有足夠的審核資訊（書況細節、清楚書封、可識別的版本資訊），以辨識並下架盜版書、違禁品、不適齡童書內容，避免法律與平台信任風險。
- **為什麼衝突**：賣家為求速度願意省略欄位、只上傳一張照片、不填寫版本／出版社資訊；但這類極簡刊登正是平台管理員難以判別盜版／違禁書的情境。若刊登流程強制要求完整欄位與多張清晰照片，平台審核能力提升但賣家棄單率上升；反之則平台法律與品牌風險升高。此衝突同時牽動 spec 的「首次刊登流程完成率 ≥ 70%」與「糾紛率 ≤ 3%」兩個成功指標，為典型的 UX／風險對立。

## AI 分析
此衝突屬於 **UX vs 合規** 的經典張力。賣家端追求的是「刊登速度」與「低摩擦」，這直接影響 GMV 與刊登完成率；管理員端追求的是「可審核性」與「風險最小化」，直接影響平台的法律暴露度。

背景考量：
1. 台灣二手書市場確實存在盜版童書、盜印教科書、侵權漫畫等灰色地帶商品，平台若無審核機制將面臨版權方法律函與下架要求。
2. 目前 spec 的驗收條件（ISBN 掃碼自動補全、手動上傳自拍封面）已部分緩解，但「沒有 ISBN 或掃描失敗」的情境是審核盲區。
3. 首次刊登流程完成率目標 70% 意味著流程每多一步驟都需成本效益評估。
4. 可能的關鍵變數：風險分級（哪類書高風險？如童書／教材／漫畫）、事前審核 vs 事後檢舉、AI 自動檢測的可行性。

## 解決方案
- [ ] 方案 1（優先滿足角色 A，賣家）：保留極簡流程，改採「事後檢舉 + AI 自動掃描 + 高風險類別抽檢」的風險控管，僅在檢舉或 AI flag 後才要求賣家補件；犧牲部分審核即時性，換取刊登完成率。
- [ ] 方案 2（優先滿足角色 B，管理員）：強制所有刊登需通過「封面清晰度檢查 + 版權頁拍照 + 版次欄位」才能送出，建立事前審核護城河；賣家棄單率可能上升，但盜版／違禁品風險大幅降低。
- [x] **方案 3（折衷，採用）**：依書籍類別採「分級審核」——低風險類別（一般小說、自我成長書）維持極簡流程；高風險類別（童書、教材、漫畫、絕版書）強制額外欄位（版權頁照、版次、出版社）；並在刊登 UI 上明確告知使用者「此類書需額外審核資訊以保障雙方權益」。

## 決策紀錄
- **決策者**：使用者本人（Spec 擁有者）
- **決策日期**：2026-04-08
- **選擇方案**：方案 3（分級審核）
- **理由**：法律風險 + KPI 雙重大——童書／教材／漫畫／絕版書是平台法律風險最大的類別，不實施分級將導致版權方發函；同時首次刊登完成率 70% KPI 不能犧牲，全量事前審核會直接崩盤。只有分級制能同時守住兩個 KPI。
- **後續行動**：
  - 角色 B User Story 新增「分級刊登」驗收條件
  - 角色 D User Story 新增「維護高風險類別清單」與「複審佇列」驗收條件

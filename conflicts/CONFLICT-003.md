# 衝突編號：CONFLICT-003

## 狀態：`detected`

## 衝突描述
- **角色 A（家長讀者）** 需要：書況描述**極為詳細**——多張清晰照片、明確標示破損／塗鴉／異味、書封與內頁狀況皆可見，才敢下單購買童書（親子共讀對書況敏感，家長對破損、污漬、異味特別在意）。
- **角色 B（書籍提供者 / 賣家）** 需要：刊登流程**簡單快速**，單本 ≤ 2 分鐘，不希望為每本書拍攝多張照片、逐項勾選書況；對繁瑣流程有棄單傾向。
- **為什麼衝突**：家長讀者的購買決策高度依賴書況資訊品質，而詳細書況（多張照片、多欄位勾選）直接拖慢賣家刊登速度，與 spec 驗收條件「單本 ≤ 2 分鐘」及「首次刊登完成率 ≥ 70%」形成拉扯。若流程要求過多，賣家棄單；若流程過簡，家長讀者不敢下單，雙邊市場都失衡。此衝突與 CONFLICT-001 類似但驅動方來自需求端而非合規端。

## AI 分析
這是經典的 **資訊不對稱 vs 刊登摩擦** 張力，也是所有 C2C 二手平台的共同難題（蝦皮、旋轉、Carousell 都面對過）。

背景考量：
1. **家長讀者敏感度特別高**：童書會進入孩子的手與口，家長對污漬、異味、破損有高度排斥；比一般二手書買家更需要書況保證。
2. **賣家端的心力分配**：一次整理 20–30 本童書的家長賣家，若每本都要拍 5 張照片 + 填 10 個欄位，實際每本需 5–10 分鐘，遠超出 spec 的 2 分鐘目標。
3. **書況爭議的後果**：書況爭議率直接進入成功指標（糾紛率 ≤ 3%），詳細資訊能降低爭議，但過度依賴事前資訊會犧牲上架速度。
4. **替代機制**：可考慮以「7 天鑑賞期 + 退款」作為資訊不對稱的兜底保險，讓買家敢於購買資訊較少的刊登。
5. **童書類別特殊性**：可針對童書類別做差異化處理，一般書維持極簡。

## 解決方案
- [ ] 方案 1（優先滿足角色 A，家長讀者）：強制所有刊登需上傳 ≥ 3 張照片（書封、書背、內頁抽樣），並勾選結構化書況欄位（破損／泛黃／污漬／異味）；賣家流程變長但買家資訊充足。
- [ ] 方案 2（優先滿足角色 B，賣家）：維持極簡流程（1 張封面照 + 自由文字書況），由 7 天鑑賞期與書況爭議退款機制兜底；買家需承擔部分資訊不對稱風險。
- [ ] 方案 3（折衷）：(a) 基本要求 1 張封面 + 極簡書況勾選（3 段式：良好／普通／明顯瑕疵）；(b) 針對「童書」類別增加第二張內頁照片為必填，並提示「家長讀者會特別檢查書況」；(c) 鼓勵而非強制詳細描述——書況照片 ≥ 3 張的刊登在搜尋結果中獲得「書況詳實」徽章與排序加分；(d) 搭配 7 天鑑賞期作為兜底。
